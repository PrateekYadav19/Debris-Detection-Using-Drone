# Debris-Detection-Using-Drone
**AI-Powered Debris Detection Using Drones**

Developed a fully offline AI-powered debris detection system for monitoring waste in coastal areas, rivers, ponds, and remote locations where manual inspection is difficult or inefficient. Unlike many existing solutions that depend on internet connectivity, our system is designed to operate entirely offline, making it reliable in areas with poor or no network coverage.

The system uses drones to capture aerial images and videos of water bodies and surrounding environments. These inputs are processed by a trained computer vision model that automatically detects, classifies, and highlights debris. A user-friendly dashboard built with Streamlit displays detection results in real time, enabling efficient monitoring and cleanup planning.

**Key Features:**

* Fully offline deployment with no internet dependency.
* Drone-based aerial monitoring for hard-to-reach areas.
* AI-powered debris detection and classification using computer vision.
* Streamlit dashboard for visualizing detected waste.
* Suitable for coastal regions, rivers, ponds, and remote environmental monitoring.

**Tech Stack:** Python, Computer Vision, Deep Learning, YOLO, OpenCV, Streamlit, Drone Imaging.
